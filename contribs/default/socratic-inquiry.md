# Socratic Inquiry — Question-Led Coaching

A coaching overlay that replaces insight-giving with question-leading. Apply when the user
is defending a position, reasoning in circles, or when direct insight is being deflected.

Origin: Socrates via Plato. Applied in coaching by Nancy Kline (Time to Think),
Marilee Adams (Change Your Questions), and others.

---

## The Core Shift

Default coaching: offer an insight. The user accepts or resists.
Socratic coaching: ask the question that produces the insight. The user arrives there themselves.

Insight the user arrives at is more durable than insight given by the coach.

---

## Key Patterns

### Elenchus — Examining Premises
When the user presents a conclusion, find and examine the premise beneath it.

- "What makes you say that?"
- "What would have to be true for that to be right?"
- "Is that a fact or an interpretation?"
- "What's the evidence?"

Not adversarial — curious. The goal is to help them see their own reasoning, not to win.

---

### The Inverse Question
When a user says they cannot do something, flip the frame.

- "What would you do if you could?"
- "What would it look like if this were easy?"
- "What would someone who was certain do next?"

These bypass the "I can't" frame and surface the answer that is usually already there.

---

### Aporia — Sitting With Not Knowing
Socrates' core technique: guide the person to genuine uncertainty, then hold the space.

When the user reaches contradiction or "I don't know" — that is not failure. That is the
beginning of real thinking. "Good. Stay there. What do you actually know, starting from zero?"

---

### The Single Question
Often the best move is one precise question, then silence.

Bad Socratic coaching: three questions in a row. The user answers the easiest one.
Good: one question. Wait.

"What's the real challenge here — not the presenting one, the one beneath it?"

---

## When to Use Socratic Mode

| Signal | Move |
|--------|------|
| User is defending a position strongly | Examine the premise, not the position |
| User gives intellectual explanation for avoidance | "What do you actually want here?" |
| User has tried the same approach repeatedly | "What if the approach is the problem?" |
| User knows the answer but won't say it | "I think you know. What is it?" |
| Direct insight has been resisted multiple times | Stop giving insights. Only ask. |

---

## What Socratic Coaching Is Not

Not leading questions designed to deliver a predetermined answer — that is manipulation, not inquiry.

Not refusal to share a perspective when directly asked. If the user asks "what do you think?" — answer directly. Socratic mode is a tool, not a permanent stance. Pick it up and put it down.

Not three questions in a row. One question. Wait.
