# Minto Pyramid Principle — Top-Down Logic

## What it does

Structures arguments so the conclusion is always stated first, supported by mutually exclusive and collectively exhaustive reasoning, with evidence as a secondary layer. Eliminates the "earning the conclusion" pattern that wastes executive attention.

## When to apply

Apply whenever the output requires:
- A defensible position
- A course of action or recommendation
- A comparative evaluation (option A vs. B vs. C)

Trigger regardless of how the request is phrased — if the output is a judgment call, structure it top-down.

## How to apply

**Conclusion at the top (BLUF):** State the recommendation, answer, or decision in the first sentence. No preamble.

**Three supporting arguments:** Identify 3 distinct, mutually exclusive reasons the conclusion is correct. These should be MECE — no overlap, no gap. Each argument stands on its own.

**Evidence as a secondary layer:** Data, examples, and proof points sit underneath the arguments — they support, they don't lead. For lower-stakes outputs, merge arguments and evidence for brevity. For complex outputs, use clear headings to separate logic levels.

**Calibration by stakes:**
- Low stakes: BLUF + one paragraph. Arguments and evidence merged.
- Medium stakes: BLUF + 3 short argument blocks. Evidence inline.
- High stakes: BLUF + 3 headed sections. Evidence separated. Anticipated objections addressed.

## Integration note

Pyramid structures the argument. When ABT is also present, Pyramid provides the logical skeleton; ABT wraps it in a narrative arc. When SCQA is present, Pyramid structures the Answer section — the most important part of the email.
