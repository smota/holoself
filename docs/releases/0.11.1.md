# Holoself 0.11.1

`holoself link remove --dry-run` no longer changes anything. Earlier versions revoked the project's entry in the self's link registry during the preview, which disabled the link while leaving the project's `link.yaml` in place ([#43](https://github.com/smota/holoself/issues/43)). The preview now only reads the registry and prints what it would revoke and remove. Confirmed removal is unchanged.

If you previewed a removal with `--dry-run` on an earlier version and kept the link, run `holoself link status --project <dir>`. If it reports the link as revoked, approve it again with `holoself link approve --project <dir>` from the self root.

## Validation and limits

Repository verification passes on Linux, Windows and macOS. New tests snapshot every file in the project and self root before and after a dry-run removal, with and without a `link.yaml`. This release does not migrate data automatically.
