# Holoself 0.10.1

Holoself now recognizes the current public skill deployed by a skills manager through a terminal directory link. Diagnostics report the deployment as external and read-only. Changed content, unsafe ancestors and permission failures remain visible; Holoself never writes through these deployments.

Codex uses `.codex/skills/holoself` and Pi uses `.pi/agent/skills/holoself` for global discovery. Selected providers supply their global skills while `AGENTS.md` remains the project instruction fallback. Existing runtimes need an explicit repair; preview it first as described in [activated links](../guides/activated-links.md).

Reviewed maintenance can now replace existing root `AGENTS.md` or `CLAUDE.md` through an explicit instruction plan. Cleanup checks source, destination and receipt paths, verifies archived bytes on replay and rolls back recoverable partial failures. Back up data before applying any reviewed maintenance plan.

## Validation and limits

Local repository verification passed with 256 tests, zero failures and one optional D01 skip. Package audit and CLI checks passed. Independent focused review covered deployment safety and cleanup rollback, including partial receipt failure. These checks establish filesystem behavior, not native host loading. Abrupt process termination still requires inspection and recovery. This release does not migrate data automatically.
