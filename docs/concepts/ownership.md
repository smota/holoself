# Ownership

> Projects own their artifacts. Self owns approved reusable personal knowledge.

| Content | Owner |
|---|---|
| Identity and preferences | Self |
| Durable career facts and evidence | Self |
| Approved reusable stories and decisions | Self |
| Job applications, company research, interview notes | Career project |
| Posts, articles, calendar, performance data | Publishing project |
| Company-specific positioning and negotiation details | Career project |
| Platform templates, media, and prompt library | Publishing project |
| Reusable insight discovered during project work | Proposal to self |

Ownership decides where source-of-truth content lives. A project may generate a view from self context, but that view must record sources and remain rebuildable. A project discovery becomes canonical only after proposal review.
