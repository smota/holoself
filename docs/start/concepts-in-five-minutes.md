# Holoself concepts in five minutes

Holoself is not a central vault for every project. It is a whole-person context protocol.

1. **Canonical self context** holds approved reusable identity, preferences, evidence, decisions, and stories.
2. **Projects** own execution artifacts such as applications, research, posts, calendars, and interview notes.
3. **Lenses** select relevant depth and permitted disclosure without creating personas.
4. **Links** let a project read self context without cloning it.
5. **Provenance** identifies source files behind context and accepted claims.
6. **Proposals** carry reusable discoveries back to self.
7. **Review** is mandatory before canonical context changes.
8. **Indexes and packets** are generated and rebuildable; Markdown remains canonical.

Core loop:

```text
inspect → use → discover → propose → review → approve/reject → validate
```
