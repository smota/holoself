# Collaboration modes

| Mode                 | Pattern                      | Use                               |
| -------------------- | ---------------------------- | --------------------------------- |
| `single-agent`       | normal orchestration         | clear routine work                |
| `advisory`           | scoped scout or critique     | focused second opinion            |
| `council`            | role-local panel             | high-uncertainty strategy         |
| `parallel-discovery` | bounded read-only fanout     | broad repository discovery        |
| `spike`              | isolated worktree experiment | uncertain implementation approach |
| `human-gated`        | human authority gate         | sensitive or high-assurance work  |

Use the smallest sufficient mode. A helper advises; the owning AgentFlow role decides.
