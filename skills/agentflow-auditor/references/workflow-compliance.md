# Workflow compliance

- SDLC config and authority namespaces validate.
- Issue labels and lifecycle state are valid.
- Role-pass provenance and transitions are complete.
- Collaboration claims have distinct, bounded evidence.
- High-assurance human gates remain present when required.
- PR manifest and release assignment validate.
- Skill identities and ownership pass the catalog validator.
- Durable evidence excludes secrets, prompts, transcripts, and unrelated logs.
